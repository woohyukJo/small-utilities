# 검증 범위

## 자동 검증

- 설치 등록 명령의 Windows 인자 전달: 기존 따옴표 오류 재현, 공백·한글 경로의 create/config 전달 검증.

- KST 04:00 전후, 동일 OS 세션의 앱 재시작, 다음 잠금 해제, 같은 날 재부팅.
- 3턴, 이전 기록 제외, 생성 중/중지/오류, 중복 완료, 명시적 재시도, DB 재개.
- 비밀번호 9회/10회, 오입력/취소/재시작 초기화, 변경, 다음 날 재잠금.
- 앱 버튼 없이 시작한 로그인, SSO/MFA/콜백 경로 변경, 빈 팝업, 로그인 완료·취소 후 제한 복원.
- 로그인 흐름은 HTTPS로 이어지고 로컬 파일·외부 앱 프로토콜은 실행하지 않음.
- 실제 Chromium의 isolated-world DOM 관찰(합성 HTML), 본문 미반출.
- 런타임 대화 설정의 일반/프로젝트 URL 정규화와 잘못된/외부 URL 거부.
- 새 DB의 미설정 상태, 대화 선택 전 활성화 거부, 설정 저장과 재시작 유지.
- A→B 대화 변경 시 A의 대기 응답 폐기, 오늘 완료 턴·잠금/해제 상태 보존, B의 과거 기록 제외.
- 같은 대화를 다시 저장할 때 pending·revision 상태 유지, A→B→A 뒤 이전 revision의 제출·완료·준비 완료 요청 거부.
- 숨겨진 실제 설정 화면: 포커스를 잃은 URL 초안 유지, 잘못된 주소 오류, 초기 설정 활성화 조건, 잠금 중 대화 재설정, 조용한 해제.
- 기존 DB에서 active-day 대화를 런타임 설정으로 비파괴 마이그레이션하고 이후 사용자가 선택한 대화를 재시작 시 덮어쓰지 않음.
- Enter·클릭 신호 없이 새 메시지가 추가된 경우 감지, 한국어 복사 버튼을 통한 완료 감지.
- 초기 테스트 0/1·1/1 표시와 활성화 후 0/3 표시 구분, 읽기 전용 진단 상태 조회.
- 실제 .NET 콘솔 호스트와 Named Pipe, 동시 중복 완료, 상태 저장, 건강 상태 보고.
- 잠금 없는 Electron 화면 렌더링. 실제 계정 로그인 없이 수행.
- 잠금 해제 시 창 크기·가시성 유지, ESC 전환 전후 입력 중인 내용·스크롤 보존(숨겨진 테스트창).
- 반복 상태 확인·변경 없는 모니터 이벤트에서 창 재배치 없음, 실제 모니터 크기 변경만 반영.
- 해제 후 정상 종료 허용, 종료 의사 저장·서비스 재시작 후 유지, 수동 재실행, 다음 날 재실행.

## 격리 Windows VM에서 수행해야 하는 시스템 검증

아래 항목은 자동 단위 테스트나 미리보기만으로 통과했다고 간주하지 않습니다.

- 실제 Electron main-process DOM/RPC 지연과 대화 변경의 동시 발생. epoch 방어 코드는 검토했지만 전체 main-process 스케줄링을 재현한 자동 검사는 별도이다.

- 설치/UAC → 설정 완료 전 미잠금 → 테스트 대화 → 활성화.
- 실제 ChatGPT 계정으로 마침표 세 번, 짧은 응답/긴 응답/정지/재생성/새로고침.
- 사용하는 로그인 제공자의 정상 로그인 및 인증 취소·재시작; 정상 콜백과 인증 팝업이 차단되지 않음.
- UI 강제 종료, 렌더러 종료/무응답, 창 숨김/최소화/위치 이탈/최상위 해제.
- 복구 중 불투명 가림 유지, 보조 프로세스 종료 후 서비스 재실행, 서비스 관리자 복구.
- 다중 모니터 추가/제거, DPI 변경, 화면 잠금·해제, 재부팅, 04:00 경계.
- 3턴 후 자동 숨김/창 크기 변경/완료 알림 없음, 해제 후 ESC로 창 모드 복원.
- 정상 잠금 상태의 가림창 최상위 반복 전환 제거 후 사용자 환경에서 주기적 깜빡임이 사라지는지 확인.
- URL 붙여넣기와 **현재 대화 선택**으로 대상 지정, 프로젝트 URL 정규화, 과거 기록 제외.
- 잠금 중 접근 불가/삭제된 대화를 수동 교체해도 이미 획득한 턴과 잠금 상태가 유지되고 자동 해제되지 않음.
- 대화 미설정 legacy 상태에서도 ChatGPT/setup 화면과 대화 지정 UI에 접근할 수 있고 잠금이 자동으로 풀리지 않음.
- MIUUYY 없이 실행; 함께 실행 순서 변경; 한쪽 로그아웃/재시작이 다른 프로필을 건드리지 않음.
- MIUUYY/Codex 대화를 병행해도 우리 대화만 계산; 설치/업데이트/제거 후 기존 설정 불변.

이 검증이 끝나기 전에는 일상 PC의 잠금을 활성화하지 마세요. 설치 패키지는 코드 서명이 없으므로
Windows에서 게시자를 확인할 수 없다는 알림이 나타날 수 있습니다.
