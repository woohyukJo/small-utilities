# BREAKDOWN

Windows에서 하루 한 번, ChatGPT와 3턴 대화하면 사용 제한을 해제합니다.
메시지 내용은 평가하지 않습니다. 마침표 하나도 정상 입력입니다.

## 실행

release의 **BREAKDOWN Setup 0.1.9.exe**를 실행합니다. 설치 마법사의 폴더 선택 화면에서
원하는 드라이브·설치 폴더를 선택할 수 있습니다. 관리자 승격은 서비스 등록에 사용합니다.
서비스 실행 경로도 선택한 설치 폴더에 맞춰 등록됩니다.
새 설치 파일 빌드가 성공하면 이전 버전 설치 파일과 blockmap을 자동 정리하고 최신 파일만 남깁니다.
설치 후 서비스가 로그인한 대상 계정에서 앱을 시작합니다.

1. ChatGPT에서 계속 사용할 대화를 열고 **현재 대화 선택**을 누르거나, 해당 대화 URL을 붙여넣어 저장합니다.
   일반 `https://chatgpt.com/c/<id>` 주소와 프로젝트의 `/g/<slug>/c/<id>` 주소를 모두 받습니다.
2. 앱 전용 비상 비밀번호를 설정합니다.
3. **로그인 / 다시 연결**에서 본인 ChatGPT 계정으로 로그인합니다.
4. 선택한 대화에서 테스트 대화 한 턴으로 현재 웹 화면의 감지가 동작하는지 확인합니다.
5. **하루 한 번 잠금 시작**을 누릅니다.

활성화 전에는 **테스트 대화 0/1 → 1/1**, 활성화 후에는 **오늘의 대화 0/3 → 3/3**으로 표시합니다.
Enter·전송 버튼 이벤트를 놓쳐도 현재 대화의 마지막 메시지 뒤에 새 사용자 메시지가 추가되면 감지합니다.
이미 있던 기록과 위로 스크롤하며 다시 표시된 과거 기록은 제외합니다.
진단용 GetDetectionStatus는 메시지 개수·감지 단계만 반환하며 대화 본문·인증 정보는 수집하지 않습니다.

그 전에는 잠그지 않습니다. 시작 후에는 모든 모니터를 가리고, 사용자 메시지 + 정상 완료된 응답
세 쌍이면 그날만 해제합니다. 오전 4시(KST)를 지나도 사용 중에는 유지하고, 다음 Windows 로그인 또는
화면 잠금 해제 때 새 하루를 적용합니다. 같은 OS 로그인 안에서 앱만 재시작하면 하루를 갱신하지 않습니다.

3턴 완료 시 잠금만 해제하며 창 크기·위치·포커스·대화 화면은 그대로 유지합니다.
자동 숨김, 완료 팝업, 소리 없이 대화를 이어갈 수 있고, **ESC를 누르면 이전 창 모드로 돌아옵니다.**
잠금 중에는 ESC로 전체화면을 벗어나지 않습니다. 비밀번호 입력창이 열려 있으면 ESC는 입력창 취소를 우선합니다.

잠금 해제 후 **트레이 우클릭 → 종료**는 창과 트레이를 완전히 닫습니다. 감시 프로세스가 이를
강제 종료로 오인해 다시 띄우지 않도록 종료 의사를 저장합니다. 같은 날은 자동으로 다시 열리지 않으며,
바로가기를 직접 실행하면 완료 상태 그대로 다시 열립니다. 다음 날 로그인·Windows 잠금 해제 때는 다시 실행됩니다.
다음 날 자동 실행을 위한 Windows 서비스는 백그라운드에 남습니다.

정상 상태의 복구용 가림창은 대화창 뒤에 유지합니다. 매 감시 주기마다 최상위로 올렸다 내리지 않고,
실제 화면 이상이 감지된 경우에만 앞으로 표시합니다.
깜빡임은 이 반복 순서 변경을 원인으로 가정해 보완한 것으로, 동일 증상의 재현·원인 확정은 완료되지 않았습니다.

**비상 해제:** 설정한 비밀번호를 10회 연속 입력합니다. 오입력, 취소, 앱 재시작은 횟수를 초기화합니다.
인터넷 장애, ChatGPT 사용량 제한, 로그인 실패, 페이지 변경은 자동 해제 사유가 아닙니다.

## 사용할 대화

사용할 ChatGPT 대화는 빌드 파일에 들어가지 않고 `%ProgramData%\BREAKDOWN\gate.db`의 설정으로 저장됩니다.
Windows 서비스가 이 값을 관리하고 앱은 서비스가 돌려주는 현재 대화 ID만 사용합니다. 새 설치에는 대화가
지정되어 있지 않으며, 대화 + 비밀번호 + 테스트 1턴이 준비되기 전에는 잠금을 시작할 수 없습니다.

- 앱 시작·새로 연결·로그인 복귀·다음 날에는 저장된 대화를 사용하며 새 대화를 자동 생성하지 않습니다.
- 일반 대화 주소와 프로젝트 경로가 같은 대화 ID를 가리키면 같은 대상으로 인식합니다.
- **현재 대화 선택**은 앱 안에 지금 열려 있는 ChatGPT 대화를 저장합니다. ChatGPT 대화가 아닌 화면에서는 저장하지 않고 오류를 표시합니다.
- 다른 대화로 바꿀 때 오늘 이미 완료한 턴, 잠금 해제 여부와 이유, 날짜, 정상 종료 상태는 유지합니다.
  이전 대화에서 완료를 기다리던 응답은 폐기하고 테스트 준비 상태만 초기화합니다. 같은 대화를 다시 저장하는 동작은 진행 중 상태를 유지합니다.
- 잠금 중에도 삭제되었거나 접근할 수 없는 대화를 다른 대화로 바꿀 수 있습니다. 이때 잠금이나 이미 획득한 진행도는 그대로이며 자동 해제하지 않습니다.
- 로그인 프로필은 기존과 같으므로 업데이트를 위해 로그인 데이터를 지울 필요가 없습니다.

## 구현과 한계

- Electron/TypeScript: 전용 프로필의 실제 ChatGPT 웹, 앱 안에서 완료하는 로그인, DOM 기반 턴 감지.
- 로그인 중 HTTPS 인증 이동·팝업·MFA를 고정 경로 목록이나 OAuth state 추정으로 막지 않습니다.
  인증은 ChatGPT와 로그인 제공자가 처리합니다. 별도 허용 단계는 없습니다.
  초기 설정 중이거나 그날의 잠금이 풀린 상태에는 사이트 이동 제한을 적용하지 않습니다.
  잠금 중에는 대화 화면으로 돌아오면 제한이 복원되고, 로그인 취소·다시 시작도 가능합니다.
- .NET 10 Windows 서비스: SQLite 상태, PBKDF2 비밀번호, 로컬 Named Pipe.
- 사용자 세션 보조 프로세스: 다중 모니터 불투명 복구 화면, 세션 이벤트, 자기 UI 감시/복구.
- 모델 API, MCP, 외부 서버, MIUUYY 실행 파일/패키지/포트에 의존하지 않습니다.
- MIUUYY는 구조만 참조했습니다. 해당 프로젝트 소스나 로그인 프로필을 가져오지 않았습니다.
- ChatGPT의 비공식 웹 UI 관찰입니다. UI 변경과 로그인 제공자의 내장 브라우저 제한으로 감지가
  중단될 수 있습니다. 이 경우 재시도/비상 해제를 사용합니다. 사용자 실제 계정과의 확인은 온보딩에서 수행합니다.
- 현재 관리자 계정을 유지합니다. 일반적인 종료/전환을 어렵게 하는 자기통제용 도구이며,
  관리자 서비스 중지, 안전 모드, 프로세스 주입, 보안 데스크톱, 물리 접근까지 차단하지 않습니다.
- 모든 제한 프로세스가 사라진 뒤 복구되기까지의 짧은 틈은 완전히 제거하지 못합니다.
- 대화 본문은 앱 DB나 로그에 별도 저장하지 않습니다. ChatGPT 자체 기록 정책과 브라우저 캐시는 별개입니다.
- 수면 연동, 모바일, 다중 기기 동기화, 자동 업데이트는 v1에 없습니다.

## 개발

Node 24+, .NET 10 SDK, Windows x64가 필요합니다.

~~~powershell
npm ci
node node_modules/electron/install.js
.\scripts\build.ps1 -Installer
~~~

SDK가 .tools/dotnet에 있으면 빌드 스크립트가 우선 사용합니다.
npm start는 **잠금 없는 미리보기**입니다. scripts/dev.ps1은 콘솔 서비스와 대화 UI를 실행하며
잠금 활성화는 허용하지 않습니다. 실제 활성화는 설치된 서비스가 시작한 --managed 앱에서만 가능합니다.
npm test는 턴/탐색 정책 테스트, native/Breakdown.Tests는 시간/SQLite/런타임 대화 설정·비상해제 테스트입니다.
scripts/ipc-smoke.cjs는 임시 DB와 전용 테스트 파이프만 쓰며 화면을 잠그지 않습니다.
scripts/ui-smoke.cjs는 실제 설정 화면을 숨겨진 Chromium에서 검사합니다. scripts/check-distribution.cjs는
패키지 버전·필수 파일·이전 개인 설정 혼입을 확인하며, 전체 빌드의 마지막 단계에서 자동 실행됩니다.
테스트가 성공하면 임시 DB와 Chromium 테스트 프로필을 정리합니다.
개인 대화 설정 파일 없이 clean checkout에서 빌드할 수 있고, 대화 선택·변경은 설치 후 런타임 설정으로 처리합니다.

설치 데이터: %ProgramData%\BREAKDOWN / 브라우저: %LOCALAPPDATA%\BREAKDOWN\browser.
개발 데이터와 미리보기는 작업 폴더 .dev에 격리합니다.
기존 MIUUYY의 .codex-chatgpt-web, 17841 포트, Codex 설정은 사용하거나 변경하지 않습니다.

실제 PC 잠금, 다중 모니터, 로그인 공급자, Windows 세션 전환은 [검증 목록](docs/VALIDATION.md)을 따릅니다.
문제 발생 시 [복구 안내](docs/RECOVERY.md)를 사용하세요.
